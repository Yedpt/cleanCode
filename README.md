## 🚀 **Visión General**

**Clean Code Blog** es una plataforma web completa (React + Node.js) diseñada para ser un punto de encuentro para desarrolladores. Permite a los administradores publicar contenido técnico y a los usuarios consumirlo de forma sencilla y agradable.

-   **Frontend Reactivo**: Interfaz de usuario moderna construida con **React** y **Vite** para una experiencia de desarrollo y de usuario ultra-rápida.
-   **Backend Robusto**: API RESTful construida con **Node.js**, **Express** y **TypeScript**, garantizando un código escalable y mantenible.
-   **Seguridad Integrada**: Autenticación basada en **JWT**, hashing de contraseñas con **bcrypt** y protección de cabeceras con **Helmet**.
-   **Base de Datos Relacional**: Persistencia de datos gestionada por **Sequelize ORM** sobre una base de datos **MySQL**.

## ⚙️ **Instalación y Ejecución**

Sigue estos pasos para levantar el entorno de desarrollo local.

**Requisitos:**
*   Node.js (v18 o superior)
*   npm (v9 o superior)
*   MySQL

### 1. **Clona el Repositorio**
```bash
git clone <URL-DEL-REPOSITORIO>
cd CleanCoders_Blog
```

### 2. **Configura el Backend**
```bash
# Navega a la carpeta del servidor
cd server

# Instala dependencias
npm install

# Crea tu archivo de entorno a partir del ejemplo
cp .env.example .env
```
Abre `server/.env` y configura tus credenciales de MySQL, el puerto de la API y un `JWT_SECRET` seguro.

### 3. **Configura el Frontend**
```bash
# Navega a la carpeta del cliente
cd client

# Instala dependencias
npm install
```
Opcionalmente, crea un archivo `client/.env` para apuntar a la URL de tu backend (ej: `VITE_API_URL=http://localhost:4000`).

### 4. **¡Lanza la Aplicación!**

Necesitarás dos terminales:

**Terminal 1 (Backend):**
```bash
cd server
npm run dev
```

**Terminal 2 (Frontend):**
```bash
cd client
npm run dev
```

🎉 ¡Listo! El frontend estará disponible en `http://localhost:5173`.

## 🔐 **Seguridad**

La seguridad es una prioridad en este proyecto. Se han implementado varias capas de protección en el backend:

-   **`Helmet`**: Añade cabeceras HTTP seguras para proteger contra vulnerabilidades conocidas.
-   **`Rate Limiting`**: Limita el número de peticiones para prevenir ataques de fuerza bruta.
-   **`CORS`**: Configuración estricta para permitir solo peticiones desde el frontend autorizado.
-   **`JWT`**: Autenticación stateless y segura para proteger las rutas privadas.
-   **`Validación de Entrada`**: `express-validator` limpia y valida todos los datos que llegan a la API.
